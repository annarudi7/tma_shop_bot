TMA Shop Telegram Bot
Интерактивный Telegram-бот с поддержкой WebApp (мини-приложения) для онлайн-продаж и приёма заказов прямо внутри мессенджера.
О ПРОЕКТЕ
Этот проект представляет собой полноценный магазин в Telegram. Пользователь может открыть удобный веб-интерфейс (WebApp) прямо в приложении, выбрать товары, оформить заказ, а бот мгновенно обработает данные и пришлет уведомление. Проект идеально подходит для демонстрации навыков разработки интерфейсов Telegram WebApp и интеграции их с ботами на Node.js.
Стек технологий
Язык: Node.js
Фреймворк для бота: node-telegram-bot-api
Веб-сервер / Frontend: Express.js, HTML / JavaScript (Telegram WebApp API)
Хостинг: Render (круглосуточная работа 24/7)
Основные возможности
Telegram WebApp: Полноценный каталог товаров с удобным интерфейсом, открывающийся внутри Telegram.
 Интерактивная корзина: Добавление товаров в корзину и оформление заказа в пару кликов.
 Обработка данных: Мгновенный приём данных от WebApp-приложения и отправка подтверждения пользователю.
Автономность: Бесперебойная работа 24/7 в облаке с защитой от спящего режима через UptimeRobot.
